# Soft Machine

An experimental, build-free studio site based on `../studio.md`.

Open `dist/index.html` in a browser, or serve the project with:

```sh
cd dist
python3 -m http.server 8000
```

The studio, contact address, and project studies are fictional creative direction. Replace them with real details before using the site for a business. The site uses Google Fonts when available, with system fallbacks.
